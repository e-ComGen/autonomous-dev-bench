# Запуск без проверки разрешения оплаты

`START.cmd` запускает платный A/B по умолчанию. Поле `AUTOBENCH_ALLOW_PAID` полностью
исключено из читаемых настроек: отсутствие, `NO`, `YES` и значение переменной
окружения не влияют на запуск. Редактировать существующий `.env` не требуется.
Нужны только действующие `GITHUB_TOKEN` и `DEEPSEEK_API_KEY`.

Распакуйте содержимое исправления в папку с используемым `START.cmd`, заменив
файлы. Папку `.bench` и `.env` не удаляйте. Запускайте обычный `START.cmd`.
После подготовки появится `Launcher: paid-ab-default-v2; confirmation prompts disabled`.

`test`, `qualify`, `ab-preflight` и справка сами по себе не вызывают платную модель.
Ограничения запросов, времени, размера ответов и прочие настройки A/B не изменены.
Гарантированного денежного потолка не добавлено. Ключи не выводятся в логи.

Это изменение загрузчика, а не новая реализация цикла. Прогоны тестов используют
явные тестовые границы приобретения runtime/отправки задания; они не заявляют
прохождение платного сквозного A/B. Предыдущие проверки runtime остаются
отдельными историческими доказательствами со своими commit.
