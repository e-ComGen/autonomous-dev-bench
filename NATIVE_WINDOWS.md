# Запуск без Docker и перезагрузки

Распакуйте весь архив в отдельную папку и откройте START.cmd. На Windows автоматически
выбирается native; WSL/Hyper-V/Docker не устанавливаются и не включаются. Нужны уже
установленные Python 3.12+ и Git. Пакеты SDK и зависимости проектов батник устанавливает
в локальные окружения .bench/native, не в глобальный Python.

Первый запуск: GitHub read token для вашего приватного ADCP (если он ещё не загружен),
подтверждение LOCAL на исполнение чужого кода локально, затем подтверждение расхода API
и скрытый ввод ключа DeepSeek. Репозиторий, issue, установка Python-зависимостей, проверка
задачи и оба варианта исполнения выбираются автоматически. Неподдерживаемые Windows
проекты отклоняются в пределах бюджета; никаких искусственных запасных задач.

Важно: native — не песочница. Код проектов, тесты и команды модели запускаются с правами
вашей учётной записи и способны читать/менять другие файлы компьютера. Venv разделяет
пакеты, но не защищает документы, SSH-ключи и скрытые тесты на уровне ОС. Очистка переменных
окружения не устраняет этот риск. Пределы CPU/RAM здесь не применяются; отчёт это отмечает.
Для недоверенного кода используйте отдельную машину или явно выбранный Docker backend.

Обычный запуск: START.cmd
Автоматизация с заранее заданными ключами и разрешённым локальным исполнением:
START.cmd ab --backend native --allow-local-execution --allow-live-model
Без платных запросов: START.cmd ab-preflight --backend native --allow-local-execution
Только подготовка настоящего issue: START.cmd qualify --backend native --allow-local-execution
Самопроверка: START.cmd test --offline

Первичная загрузка зависимостей требует интернет. На каждом запуске инструменты и внешняя
проверка получают новое окружение из ранее зафиксированных wheel-файлов. Эталонное
исправление не устанавливается в окружение агента. Его рабочая копия содержит pre-fix код.
Повтор выбора: --replay <сохранённый selection.json>, тот же архив/настройки и сохранённая .bench.
Native и Docker записи окружений не взаимозаменяемы; неподходящий replay прекращается явно.

Число задач/попыток, лимиты времени/запросов и параметры поиска — AB.toml.
Результат: .bench/latest.json -> summary.json и RESULT.md. Полные логи открываются только
для диагностики. Кодексу достаточно AGENTS.md и этих файлов, а не всего дерева .bench.

Это сравнение с существующим PR28 ADCP, не доказательство исполнения отдельного
неопубликованного vNext-архива. Успешная самопроверка или SDK transport fixture не являются
платным A/B и не доказывают улучшение модели.
